# gTheoryShiny EPM submission materials

- `gTheoryShiny_EPM_manuscript.docx`: APA-style manuscript with the author list and affiliations supplied by the authors.
- `gTheoryShiny_EPM_manuscript_blinded.docx`: blinded review copy with author-identifying title-page and author-note information removed.
- `figures/`: screenshots captured from the running application.
- `results/`: generated synthetic data, variance benchmarks, D-study projections, bootstrap intervals, Monte Carlo outputs, and browser verification.
- `scripts/validate_application.R`: reproducible validation script.
- `scripts/capture_app.cjs`: browser capture and worked-example check.

Author order: Zhehan Jiang, Jihong Zhang, and Tianpeng Zheng. Jiang and Zhang are co-first authors. Jiang and Zheng are co-corresponding authors. The corresponding email supplied for Jiang is jiangzhehan@bjmu.edu.cn.
